# FORMA — Construction & Architecture Website

FORMA is a modern construction and architecture website built using HTML5, CSS3, and Bootstrap 5. Designed with elegant typography, architectural imagery, and a clean visual layout, it creates a professional digital presence for a construction company.

The website features a stylish navigation bar, an engaging hero section, company statistics, an about section, four service categories, featured projects, a working process section, and a dedicated contact area. A professionally structured footer completes the overall design.

The project focuses on modern UI design, responsive layouts, balanced spacing, visual hierarchy, and clean content organization. It demonstrates the practical use of HTML5, CSS3, and Bootstrap 5 to create an attractive and professional business website.
